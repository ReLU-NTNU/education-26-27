# Bootcamp 7 · Tree models and hyperparameter optimization

Original Jupyter notebooks from the 2025–2026 course, copied unchanged:

- [Random Forest Classification](Random%20Forest%20Classification.ipynb):
  classification, tree visualization, feature importance, alternative model
  settings and XGBoost.
- [Random Forest Regression](Random%20Forest%20Regression.ipynb): housing-price
  prediction, comparison with linear regression, feature importance and XGBoost.
- [Hyperparameter Optimization](Hyperparameter%20Optimization.ipynb): grid
  search, random search, cross-validation and a pipeline example.

These notebooks contain completed code examples. The planned introductory
single-tree exercises and marimo conversion have not been added yet.
This import has been checked for notebook JSON validity and exact agreement
with the source, but the notebooks have not been rerun.

## Existing Bootcamp 2 users

Continue using the setup and start commands in `bootcamp_2/` as before.
This folder does not change Bootcamp 2's environment, lockfile, launchers or
saved answers. The notebooks remain in Jupyter format and do not yet have a
dedicated setup script here. Keep any environment for these notebooks separate
from `bootcamp_2/.venv`.
