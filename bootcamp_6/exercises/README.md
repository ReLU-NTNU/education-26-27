# Student workbook

Open this workbook using `../scripts/start.sh` (PowerShell: `..\scripts\start.ps1`).
The launcher creates a personal copy at `../work/exercises.py` and preserves it.

See the [setup instructions](../README.md). Fill in the `WRITE HERE` blanks in
[workbook.py](workbook.py); the worked answers are kept separately in `../solutions/`.
